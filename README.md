#  Number Guessing Game (Rust)

A fun little terminal game built in Rust where you try to guess a randomly generated number. Simple idea, but it’s a good way to practice loops, input handling, and basic game logic.

---

##  How the game works

- The computer picks a random number between **1 and 100**
- You keep guessing the number
- After each guess, the game gives you hints:

   Too high  
   Too low  
  Correct guess = win!

You keep going until you get it right.

---

##  What I learned building this

- Handling user input in Rust
- Using loops (`loop`, `break`)
- Working with the `rand` crate 
- Comparing values using `match`
- Building a simple CLI project from scratch

---

## ⚙️ Tech Stack

- 🦀 Rust (main language)
-  rand crate (random number generator)
-  Terminal / CLI based app

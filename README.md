# 🎯 Number Guessing Game (Rust)

A simple terminal-based number guessing game built using Rust. The program generates a random number and the player tries to guess it with hints along the way.

---

## 🧠 How it works

- The program generates a random number between 1 and 100
- The user keeps entering guesses
- The game tells you if your guess is:
  - Too high 📈
  - Too low 📉
  - Correct 🎉

---

## ⚙️ Tech Stack

- Rust 🦀
- rand crate (for random number generation)
- Standard input/output (terminal-based interaction)
